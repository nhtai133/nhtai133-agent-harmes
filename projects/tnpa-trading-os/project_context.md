# TNPA Trading OS Project Context

## Project Mission

TNPA Trading OS exists to preserve, structure, and operationalize trading knowledge for TNPA-style trading work inside Agent Harmes.

The project should act as a long-term context layer for trading strategy decisions, EA development, dashboard planning, market analysis, review history, and risk discipline. Its primary mission is to help the Commander and specialist agents avoid repeated rediscovery, preserve approved assumptions, and maintain consistent trading judgment across execution cycles.

## Scope

This project covers durable project knowledge for:

- TNPA trading principles, strategy assumptions, and decision logic.
- EA planning, review, validation, and release preparation.
- Market analysis used to support TNPA trading decisions.
- Risk management standards for trade design, testing, and operational review.
- Dashboard or reporting requirements related to TNPA trading operations.
- Lessons learned from completed strategy, analysis, testing, and review cycles.
- Known issues that affect trading quality, system reliability, or decision confidence.

This project does not contain:

- Broker credentials, account passwords, API keys, or private financial data.
- Raw implementation code.
- Unsanitized trade logs, personal data, or sensitive account exports.
- Unapproved strategy claims treated as confirmed facts.
- Final investment, financial, or trading advice for external users.

## Goals

- Maintain a reliable project memory that agents can use before planning or executing TNPA work.
- Keep trading rules, risk rules, and coding expectations visible across workflows.
- Record assumptions, decisions, lessons, and unresolved issues in a form that remains useful over time.
- Support repeatable handoffs between Commander, Planner, Researcher, Coder, Tester, and Reviewer agents.
- Reduce repeated mistakes by turning review findings and testing failures into durable memory.
- Preserve the distinction between confirmed rules, working assumptions, open questions, and rejected ideas.
- Improve future EA, dashboard, content, and market-analysis workflows by giving agents a shared project context.
